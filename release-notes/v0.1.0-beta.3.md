# Tubely 0.1.0 Beta 3

Beta pengembangan Studio Live untuk Android 8.0+ (API 26), package `dev.tubely`, version code 4.

## Fitur dan perbaikan

- Studio Live untuk TikTok, YouTube, dan server RTMP/RTMPS melalui Server URL + Stream Key.
- Komposisi layar/game, kamera, avatar, gambar, dan teks; panel layer, scene, audio, dan tujuan.
- Layout portrait/landscape, drag/resize/rotate/crop, urutan layer, serta cut/crossfade scene.
- Mixer mikrofon dan internal audio (Android 10+ dan aplikasi sumber yang mengizinkan capture), dengan volume/mute terpisah.
- Preset Hemat sebagai default: 360 x 640, 24 fps, target video 1,4 Mbps. Komposisi GPU, antrean audio/network dan cache aset dibatasi; performa nyata perangkat spek rendah belum diukur.
- Perbaikan decoder APNG untuk animasi avatar. Preview tata letak yang belum aktif sengaja memakai thumbnail frame pertama.
- Reconnect terbatas, statistik sesi, penanganan thermal, scene aman, dan penyimpanan kredensial terenkripsi.
- Output URL overlay lokal/LAN dan floating window tetap tersedia. Backup profil tetap `.tbly`.

## Batas beta

- Pengujian perangkat, siaran ke akun nyata, audio sync, reconnect jaringan, perlindungan capture per-frame, dan sesi panjang/performa belum dilakukan karena ADB tidak mendeteksi perangkat saat rilis disiapkan. Ini prerelease untuk pengujian pengguna.
- Koneksi akun YouTube memerlukan konfigurasi Google Cloud, YouTube Data API v3, OAuth Android untuk package/sertifikat rilis, dan consent screen. Gunakan URL/key manual selama konfigurasi tersebut belum tersedia. Akun TikTok harus memiliki akses Server URL dan Stream Key.
- Full-display capture dapat menampilkan layer layar hitam ketika Tubely dibuka karena perlindungan jendela pribadi. Gunakan single-app sharing atau scene aman. Hentikan capture sebelum mengubah kredensial.
- Dukungan encoder hardware, kamera, internal audio, dan izin capture bergantung perangkat dan kebijakan aplikasi sumber.

## Instalasi

Unduh APK pada Assets. Ditandatangani dengan sertifikat yang sama seperti Beta 2 sehingga dapat dipasang sebagai pembaruan. Cadangkan profil `.tbly` sebelum mencoba beta.
