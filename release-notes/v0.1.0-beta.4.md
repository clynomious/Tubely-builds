# Tubely 0.1.0 Beta 4

Beta untuk Android 8.0+ (API 26), package `dev.tubely`, version code 5.

## Perubahan

- Maskot kiri atas kembali untuk mengecilkan panel chat menjadi maskot. Opacity dibuka dari tombol kiri bawah; tombol resize lama dihapus karena ukuran panel bisa diubah lewat drag sudut kanan bawah.
- Tombol kanan atas menjadi End stream dengan popup konfirmasi. Cancel, Back, atau dismissal tidak menghentikan siaran. Konfirmasi menghentikan pengiriman dari Tubely dan menutup monitor; bukan janji bahwa platform langsung mengubah status LIVE.
- Monitor TikTok native melalui adaptasi protokol PirateTok/live-java: chat, penonton saat ini, total penonton LIVE dan likes. Statistik memakai ikon dan angka di bawah username; nilai yang belum diterima tampil sebagai tanda strip. Tidak memerlukan API key atau login TikTok di Tubely.
- Panel lebih rapat; slider opacity dan detail tambahan disembunyikan sampai dibuka. Maskot tanpa latar, ikon kecil dengan area sentuh tetap nyaman.
- Click-through memiliki tombol buka kunci yang tetap bisa disentuh, serta recovery dari notifikasi/menu Studio. Opacity adalah pengaturan terpisah dan tidak berubah otomatis saat click-through diaktifkan.
- Overlay chat terbuka otomatis saat koneksi stream tersambung, dengan pengaturan auto-open dan username di tab Live chat.
- Permintaan capture memakai dialog standar Android agar pilihan satu aplikasi tersedia. Preview Activity yang hilang saat game dibuka tidak lagi menghentikan capture; virtual display/surface dipertahankan saat resize dan pergantian scene.
- Opsi 1080p/30fps ditambahkan. Mode Hemat 360p/24fps tetap default, dengan buffer/cache terbatas dan komposisi GPU. Angka ini konfigurasi, bukan hasil benchmark perangkat.

## Catatan beta

- Capture game, encoder hardware, audio internal dan keandalan background bergantung perangkat/izin/kebijakan aplikasi sumber. Pilih game pada dialog capture, bukan Tubely. Android lama dapat hanya menyediakan seluruh layar.
- Monitor operator memakai jendela terlindungi. Capture seluruh layar bisa menampilkan blok hitam di area panel; gunakan capture satu aplikasi game untuk memisahkan monitor.
- Android 12+ dapat menolak sentuhan ke game jika opacity melampaui batas sistem atau beberapa overlay bertumpuk. Atur opacity sendiri; click-through tidak menurunkannya otomatis.
- PirateTok adalah protokol tidak resmi yang bisa berubah/diblokir TikTok. Hanya data yang benar-benar diterima yang ditampilkan; maksimal 80 pesan disimpan di memori (50 terlihat), lalu dibersihkan saat monitor ditutup.
- Pengujian siaran akun nyata, penerimaan video/chat di TikTok dan sesi panjang/performa spek rendah belum menjadi bukti penerimaan rilis ini.
- Integrasi akun YouTube memerlukan konfigurasi Google Cloud/OAuth eksternal. URL dan stream key manual tetap tersedia.
- Backup profil memakai `.tbly`. Overlay avatar/URL lokal-LAN tetap tersedia; video recording berada di luar cakupan.

## Instalasi

Unduh APK dari Assets. Sertifikat tetap sama dengan beta sebelumnya sehingga dapat dipasang sebagai pembaruan. Cadangkan profil `.tbly` sebelum mencoba beta.
