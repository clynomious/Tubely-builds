# Tubely 0.1.0 Beta 8

## Baru dan diperbaiki

- **Editor Studio lebih nyaman.** Properti layer sekarang berada di bawah preview pada HP atau di sampingnya pada layar lebar. Preview tetap terlihat saat mengatur item; pengaturan dipisahkan ke tab Transform dan Source.
- **Drag urutan layer.** Tarik ikon tiga garis di kanan tombol kunci untuk mengubah urutan. Tombol naik/turun terpisah diganti dengan kontrol ini.
- **Transform lebih lengkap.** Posisi dan ukuran dalam piksel output, rasio terkunci, rotasi, crop, flip horizontal/vertikal, sembilan titik anchor, fit/fill/stretch, perataan tengah, opacity dan reset. Transform bisa disalin ke layer lain.
- **Alur penyuntingan baru.** Undo/redo hingga 20 langkah, snapping yang bisa dimatikan, duplikasi gambar/teks, serta edit teks langsung di panel.
- **Source video lokal.** Tambahkan video dengan play/pause, restart, seek, loop, mute dan volume. Satu video per scene; file maksimal 128 MiB, hingga 1080p/60 fps sesuai decoder perangkat. Video memakai decoder hardware dan komposisi GPU; audio masuk ke mixer Studio.

## Coba pembaruan dalam aplikasi

Dari **Beta 7**, buka **About / Tentang → Cek pembaruan → Unduh → Pasang**. Pemeriksaan manual tidak menunggu interval cek otomatis. Izinkan pemasangan dari Tubely jika diminta Android. Pembaruan menggunakan sertifikat yang sama dan version code yang lebih tinggi.

APK juga tersedia langsung di Assets. Android 8.0+, versi `0.1.0-beta.8`, version code `9`. Ukuran APK: 3,978,656 bytes.

## Pemeriksaan beta

- Build signed/minified berhasil; **70 tes JVM lulus**, tanpa gagal atau dilewati.
- Lint: **0 error / 139 warning**. Laporan lint, checksum, inventaris dependensi dan audit disertakan.
- OSV tidak menemukan advisory pada 124 dependensi runtime yang diperiksa. Ini bukan audit keamanan menyeluruh.
- Belum diuji di HP: playback/seek/audio video, drag dan keyboard, siaran nyata, performa perangkat, serta proses unduh/pasang melalui updater. Tidak ada klaim pengukuran performa atau jaminan 1080p/60 fps pada semua perangkat. Dalam preview komposisi yang belum aktif, video ditampilkan sebagai thumbnail.
