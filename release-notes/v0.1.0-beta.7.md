# Tubely 0.1.0 Beta 7

## Baru dan diperbaiki

- **Ekspor `.tbly` diperbaiki.** Tipe file lebih kompatibel dengan penyimpanan Android, nama berakhiran `.tbly` dipertahankan, dan arsip disiapkan lengkap sebelum ditulis. File tujuan yang gagal ditulis dibersihkan. Impor juga dapat memilih file yang tipe MIME-nya tidak dikenali.
- **Studio Live lebih bersih.** Preview lebih luas, layout berdampingan pada layar lebar, properti source dalam panel terpisah, dan pengaturan lanjutan bisa dilipat. Deskripsi panjang dipangkas. Mengakhiri stream meminta konfirmasi.
- **Browser URL sebagai source.** Tambahkan overlay HTTP/HTTPS ke komposisi, atur ukuran browser dan muat ulang bila perlu. Satu browser aktif per scene; render browser dibatasi 15 fps untuk membatasi beban, terpisah dari FPS stream.
- **Halaman About.** Tautan GitHub, TikTok dan Instagram `@clynomious`, serta kartu dukungan [Trakteer](https://trakteer.id/clynomious).
- **Pembaruan dalam aplikasi.** Cek GitHub otomatis saat membuka aplikasi, atau cek manual dari About. Unduh APK langsung lalu pasang melalui installer Android. Unduhan diperiksa sebelum pemasangan; Android tetap meminta izin/konfirmasi. Fitur ini tersedia mulai Beta 7 untuk pembaruan berikutnya.

## Instalasi

Unduh APK di Assets dan pasang sebagai pembaruan beta sebelumnya. Sertifikat tetap sama. Cadangkan profil `.tbly` sebelum memperbarui.

## Pemeriksaan beta

- Build signed/minified berhasil; **56 tes JVM lulus**, termasuk nama file `.tbly`, arsip profil dan urutan versi updater.
- Lint: **0 error / 134 warning**. Laporan, checksum dan daftar dependensi disertakan. OSV tidak menemukan advisory pada 124 dependensi runtime yang diperiksa.
- Pengujian HP belum dilakukan. Ekspor melalui penyedia file, browser overlay, download/pemasangan update dan siaran nyata masih memerlukan validasi di perangkat. Resolusi/FPS aktual mengikuti kemampuan perangkat dan sumber.
