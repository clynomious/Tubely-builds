# Tubely 0.1.0 Beta 5

Beta untuk Android 8.0+ (API 26), package `dev.tubely`, version code 6.

## Perubahan

- Chat TikTok menyambung ulang ketika stream mulai mengirim, termasuk jika monitor sudah dibuka sebelumnya. Selama broadcasting, reconnect terus dicoba dengan backoff, jitter dan jeda lebih panjang setelah kegagalan berulang atau penolakan. Tombol reconnect manual tersedia. Cookie anonim dipakai ulang dan redirect dibatasi ke HTTPS TikTok; tidak memakai login akun atau jasa penandatanganan pihak ketiga.
- Optimasi beban streaming: buffer pengiriman dibatasi 48 paket; snapshot chat dan baris pesan dipakai ulang; pembacaan tekstur sumber yang berulang dihapus. Komposisi tetap melalui GPU dan hanya ada satu tangkapan mikrofon.
- Performa adaptif mempertahankan resolusi pilihan dan mengurangi FPS render saat beban berkelanjutan, frame terbuang atau suhu meningkat, lalu memulihkannya secara bertahap. 1080p dimulai pada target 24 fps saat opsi ini aktif; matikan untuk target preset 30 fps. Mode Hemat tetap menjadi default. Ini perilaku konfigurasi, bukan jaminan hasil benchmark.
- Peredam noise mikrofon aktif secara default dan bisa dimatikan di tab Audio. Memakai NoiseSuppressor perangkat bila tersedia, dengan filter spektral ringan sebagai cadangan. Audio game tidak ikut difilter. Filter cadangan menambah sekitar 21 ms penundaan; kualitas suara nyata belum dievaluasi di perangkat.
- Monitor chat bertema gelap dengan aksen lavender, tiga titik di tengah atas sebagai penanda drag, serta pegangan resize di luar sudut kiri bawah dan kanan bawah. Pegangan memudar saat diam dan muncul saat disentuh. Slider opacity berada langsung di atas kontrol bawah dan tetap bisa disembunyikan.
- Jendela monitor tidak lagi memakai proteksi capture yang menyebabkan kotak hitam pada tangkapan seluruh layar. **Berbagi seluruh layar sekarang menyertakan isi panel chat dan kontrolnya.** Pilih satu aplikasi game untuk menjaga monitor di luar siaran. Proteksi kredensial di Activity Tubely tetap dipertahankan.
- Maskot untuk minimize, konfirmasi End stream, serta click-through dengan tombol unlock yang tetap bisa disentuh dipertahankan. Click-through tidak mengubah opacity; pemulihan dari notifikasi/Studio tetap tersedia.

## Catatan beta

- PirateTok adalah protokol tidak resmi; TikTok dapat mengubah atau menolak koneksi. Auto reconnect tidak menjamin akses chat ketika TikTok memblokir koneksi. Statistik hanya muncul setelah datanya diterima.
- Pengujian HP dilewati karena perangkat tidak tersedia. Koneksi chat akun LIVE, hasil capture di sisi penonton, kualitas peredam noise, penggunaan CPU/GPU/RAM dan kelancaran stream resolusi tinggi belum divalidasi di perangkat untuk rilis ini.
- Dukungan encoder hardware, capture game dan audio internal mengikuti kemampuan perangkat serta kebijakan aplikasi sumber. Tubely tidak menyiarkan isi aplikasi yang dilindungi.
- Android 12+ bisa memblokir sentuhan ke game jika opacity melebihi batas sistem atau overlay bertumpuk. Atur opacity sendiri sebelum mengaktifkan click-through.
- Integrasi akun YouTube membutuhkan konfigurasi Google Cloud/OAuth eksternal. URL dan stream key manual tetap tersedia.
- Backup profil memakai `.tbly`. Overlay URL lokal/LAN dan floating avatar tetap tersedia; video recording di luar cakupan.

## Instalasi

Unduh APK dari Assets dan pasang sebagai pembaruan. Sertifikat tetap sama dengan beta sebelumnya. Cadangkan profil `.tbly` sebelum mencoba beta.
