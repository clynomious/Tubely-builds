# Tubely 0.1.0 Beta 9

## Baru dan diperbaiki

- **Cek update saat aplikasi dibuka.** Pembaruan yang tersedia ditawarkan langsung tanpa perlu membuka About terlebih dahulu. Jeda enam jam yang tersimpan dihapus; perpindahan cepat ke izin/installer dibatasi satu cek per menit. Unduh dan pemasangan tetap melalui tindakan pengguna serta konfirmasi Android.
- **Slider transform layer.** Posisi X/Y, ukuran, rotasi dan empat sisi crop dapat diatur dengan slider. Input angka tetap tersedia, termasuk kunci rasio ukuran dan nilai negatif. Properti tetap berada di panel bawah/samping preview.
- **Overlay chat lebih ringkas.** Grip resize kiri bawah dihapus; grip seperempat lingkaran kanan bawah tetap terlihat dan dapat ditarik.
- **Durasi dan koneksi live.** Ikon jam serta jaringan di bawah username menampilkan durasi live dan status koneksi stream/bitrate. Durasi berlanjut saat reconnect. Status koneksi chat tetap ditampilkan terpisah.
- **Penutupan Live Monitor diperbaiki.** Pembersihan socket/HTTP dipindah ke background, penutupan berulang aman, reconnect setelah penutupan ditolak, dan callback window yang terlambat diabaikan. Menutup monitor tidak menghentikan stream.

## Instalasi

Unduh APK di Assets atau gunakan pemeriksaan manual di **About / Tentang** pada versi sebelumnya. Perubahan cek otomatis saat membuka aplikasi berlaku mulai Beta 9. Sertifikat tetap sama agar bisa dipasang sebagai pembaruan.

Android 8.0+, versi `0.1.0-beta.9`, version code `10`. Ukuran APK: 3,983,148 bytes.

## Pemeriksaan beta

- Build signed/minified berhasil; **76 tes JVM lulus**, tanpa gagal atau dilewati. Termasuk penjadwalan cek update, durasi/status koneksi dan lifecycle penutupan chat.
- Lint: **0 error / 137 warning**. Checksum, laporan lint, inventaris dependensi dan audit disertakan.
- OSV tidak menemukan advisory pada 124 dependensi runtime yang diperiksa; ini bukan audit keamanan menyeluruh.
- Pengujian HP belum dilakukan. Crash Close Live Monitor yang dilaporkan belum direproduksi dengan stack trace perangkat; perbaikan menangani jalur teardown yang tidak aman dari pemeriksaan source. Slider/gesture, overlay, updater unduh/pasang dan siaran nyata masih perlu validasi perangkat. Tidak ada pengukuran performa baru.
